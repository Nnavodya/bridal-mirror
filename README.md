## 📖 About The Project

**Bridal Mirror** is a mobile application that allows Sri Lankan brides to virtually try on sarees, jewellery, and makeup styles from the comfort of their home — without visiting multiple boutiques.

Sri Lanka's bridal market lacks a culturally specific virtual try-on solution that caters to local styles such as Kandyan osariya, traditional gold jewellery, and South Indian bridal looks. Bridal Mirror addresses this gap by providing a realistic, convenient, and culturally relevant bridal styling experience.

---

## ✨ Features

- 📸 **Photo Upload** — Upload a photo from gallery or capture using camera
- 💍 **Jewellery Try-On** — Virtually overlay necklaces, earrings, and maang tikka
- 👗 **Saree Preview** — Preview saree styles and colors on your photo
- 💄 **Makeup Styles** — Try different lipstick shades and eye makeup looks
- 🛍️ **Product Catalog** — Browse items by category with filters
- ❤️ **Saved Looks** — Save and revisit your favourite bridal looks
- 📲 **WhatsApp Share** — Share your looks instantly with family and friends

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or above)
- Expo Go app installed on your Android device
- Git

### Installation

1. Clone the repository
```bash
git clone https://github.com/Nnavodya/bridal-mirror.git
```

2. Navigate to the project directory
```bash
cd bridal-mirror
```

3. Install dependencies
```bash
npm install
```

4. Start the development server
```bash
npx expo start
```

5. Scan the QR code with **Expo Go** app on your Android device
